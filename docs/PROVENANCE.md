# Code provenance and licenses

Audit date: 20 October 2026. Scope: every tracked file in the repository, its dependencies, and the datasets the project uses.

## Source code

- All 45 tracked files were written for this project. Git history has one author, Sainikhil Juluri.
- No file contains a third-party copyright header, license header, or copied attribution block. A search for other projects' names found none.
- The project does not contain code from the `realtime-recsys` repository referenced in an earlier conversation. The implementation is independent, and the README says so only where it is relevant.
- The `egg-info` build folder is not tracked. It is generated by `pip install -e .` and ignored by `.gitignore`.

## Datasets

| Dataset | Used by | License | Status |

## Attribution

- MovieLens data is referenced in the README and the loader docstring with the GroupLens URL. The dataset itself is not included.
- Music4All-Onion will require citing Moscati et al., CIKM 2022, as its authors request. That citation will go in the README when the dataset is used.
